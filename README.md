# TheHomiesML

Machine-learning project for classifying human-authored and machine-generated
text without deep-learning models.

## Repository structure

- `data/splits/` - shared fixed train/validation split
- `notebooks/` - report-oriented Jupyter notebooks
- `scripts/` - reproducible model training and submission generators
- `results/` - validation scores, tuning tables and aligned predictions
- `src/` - shared evaluation and submission helpers
- `submissions/` - Kaggle-ready `id,label` files
- `reports/` - figures and report assets
- `docs/` - experiment instructions

See `docs/model_experiments.md` for commands and output filenames.
